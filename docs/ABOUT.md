# About

Shape the language to fit the problem.

[Racket][racket-lang] is a general-purpose language in the Lisp and Scheme tradition.
Start with small functions and begin building concise, expressive programs using Racket's rich collection of datatypes and iteration forms.
When you need more, macros let you add new syntax, and `#lang` lets you write programs in entirely new languages.

[racket-lang]: https://racket-lang.org/
